# Подключение VPS и первый запуск

Сервер: `138.16.164.156`, Ubuntu 26.04, 2 vCPU / 4 ГБ / 100 ГБ.
Ubuntu 26.04 поддерживается Docker Engine. Скрипт `deploy/bootstrap.sh` устанавливает Docker из официального apt-репозитория, Compose, rclone и создаёт пользователя deploy. Существующие SSH-настройки не меняет и контейнерные пакеты не удаляет.

## Если SSH не подключается

`Connection timed out during banner exchange` означает, что приветствие SSH не получено. Проверка пользовательского ключа ещё не началась. Причина может быть в незавершённой установке ОС, sshd, firewall или сети между компьютером и VPS; по одному тайм-ауту причину установить нельзя.

В веб-консоли провайдера после завершения установки проверить:

```bash
systemctl status ssh.service ssh.socket --no-pager
ss -ltnp | grep ':22'
ufw status
```

Уточнить внешний SSH-порт в панели и правила сетевого firewall. Не отключать firewall целиком и не пересоздавать сервер для диагностики. Приватный SSH-ключ и пароль root в чат не отправлять.

## Доступ без домена

Перед первым деплоем записать `tunnel` в `/opt/market/admin-mode`. Deploy использует `compose.tunnel.yaml`: админка слушает только `127.0.0.1:8000` на VPS, Caddy не запускается. С компьютера открыть туннель:

```powershell
ssh -N -L 8000:127.0.0.1:8000 deploy@138.16.164.156
```

После этого открыть `http://localhost:8000`. HTTP идёт внутри SSH-туннеля, наружу порт 8000 не публикуется. Пароль админки остаётся обязательным. В этом режиме cookie Secure отключён только override-файлом для loopback-доступа.

## Переход на домен

1. Создать A-запись поддомена на IP VPS.
2. Записать домен и `https://...` в DOMAIN/PUBLIC_URL файла `/opt/market/.env`, сохранить COOKIE_SECURE=true.
3. Установить `/opt/market/admin-mode` в `https`.
4. Выполнить следующий deploy.sh: стандартный compose запускает Caddy и убирает временную публикацию 8000.
5. Проверить сертификат и вход в админку.

Токены трёх ботов, JAHA_API_KEY и DATA_KEY хранятся только в `/opt/market/.env` с правами 600. GitHub Actions получает отдельный SSH-ключ пользователя deploy, а не личный ключ владельца. Google Drive подключается отдельно по `google-drive-backups.md`.
