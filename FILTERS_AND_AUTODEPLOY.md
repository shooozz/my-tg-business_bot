# Фильтры и автодеплой

## ✅ Реализовано

### 1. Фильтрация в админке

В разделе **Товары** добавлены мощные фильтры для удобной работы с каталогом:

#### Доступные фильтры:

- **По провайдеру** — показывать товары только от Jaha, Canboso или всех поставщиков
- **По категории** — фильтровать по категориям товаров (например, Spotify, Netflix, Games и т.д.)
- **По статусу**:
  - В продаже — только видимые товары
  - Скрыто — скрытые товары
  - Нет в наличии — товары, которые закончились у поставщика

#### Как использовать:

1. Откройте раздел **Товары** в админке
2. Используйте выпадающие списки над таблицей товаров
3. Поиск работает вместе с фильтрами
4. Кнопка **Сбросить** очищает все фильтры

Счетчик показывает: `Показано: X из Y` — сколько товаров отображается после применения фильтров.

### 2. Вкладка "Провайдеры"

Новая вкладка **⚡ Провайдеры** показывает:

- Список настроенных провайдеров (Jaha, Canboso)
- Какой провайдер установлен по умолчанию
- Баланс каждого провайдера в USDT
- Кнопки синхронизации:
  - **Загрузить все провайдеры** — обновить каталог от всех поставщиков
  - **Только jaha** / **Только canboso** — синхронизировать конкретного провайдера

### 3. GitHub Actions автодеплой

Создан workflow `.github/workflows/ci.yml` для автоматического деплоя:

#### Что делает CI/CD:

**Test job** (всегда запускается):
- Установка Python и зависимостей
- Запуск pytest
- Сборка Docker образа
- Проверка docker-compose конфигурации

**Deploy job** (только при push в main):
- Настройка SSH подключения
- Архивирование кода через `git archive`
- Загрузка на сервер через SCP
- Запуск `deploy/deploy.sh`
- Проверка деплоя

#### Как настроить автодеплой:

Следуйте инструкциям в [AUTODEPLOY_SETUP.md](AUTODEPLOY_SETUP.md):

1. Получите SSH fingerprint сервера
2. Добавьте GitHub Secrets в environment `production`:
   - `DEPLOY_HOST` = `213.59.113.102`
   - `DEPLOY_USER` = `deploy`
   - `SSH_PRIVATE_KEY` = приватный ключ
   - `SSH_KNOWN_HOSTS` = результат ssh-keyscan

3. Добавьте GitHub Variable:
   - `DEPLOY_ENABLED` = `true`

4. Каждый `git push origin main` автоматически:
   - Запустит тесты
   - Деплоит на сервер (если тесты прошли)
   - Создаст backup БД
   - Запустит новые контейнеры

#### Безопасность:

- ✅ Деплой только из main ветки
- ✅ Только проверенный код (прошедший тесты)
- ✅ Каждый деплой в отдельной директории
- ✅ StrictHostKeyChecking включен
- ✅ Секреты зашифрованы в GitHub

#### Откат:

```bash
ssh -i ~/.ssh/market_deploy deploy@213.59.113.102
ls -lt /opt/market/releases/
bash /opt/market/releases/<PREVIOUS_SHA>/deploy/deploy.sh <PREVIOUS_SHA>
```

## Технические детали

### Структура файлов:

```
app/static/
├── app.js          # Интегрированы фильтры и вкладка провайдеров
├── filters.js      # Логика фильтрации
├── style.css       # Стили для фильтров
└── index.html      # HTML с новыми элементами

.github/workflows/
└── ci.yml          # GitHub Actions workflow

app/providers/
├── manager.py      # Управление несколькими провайдерами
├── jaha.py         # Jaha API provider
└── canboso.py      # Canboso API provider
```

### API endpoints:

- `GET /api/dashboard` — возвращает `providers` и `balances`
- `POST /api/sync` — синхронизация всех провайдеров
- `POST /api/sync?provider=jaha` — синхронизация конкретного провайдера

### Data attributes:

Каждая строка товара теперь имеет атрибуты:
- `data-provider` — название провайдера
- `data-category` — категория товара
- `data-visible` — видимость (true/false)
- `data-available` — наличие (true/false)
- `data-search` — строка для поиска

Фильтры работают через эти атрибуты без необходимости поиска в `window.marketData`.
