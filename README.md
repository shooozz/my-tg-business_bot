# Market — Telegram-магазин с двумя админками и поддержкой

Один репозиторий, один сервер, три Telegram-бота и веб-панель. Это первая версия, которую нужно проверить на тестовых ботах и контрольной закупке перед открытием продаж.

## Что реализовано

- Клиентский бот: каталог с пагинацией, полное описание, ручная/автоматическая выдача, сбор buyer_input по схеме Jaha, подтверждение условий, Stars, история и выдача.
- Бот администратора: каталог, цены, видимость, заказы, обращения, ответы, запрос возврата.
- Бот поддержки: отдельные обращения, приём текста/фото/файлов, доставка ответов от имени бота. Личный аккаунт администратора не раскрывается. Фото и файлы просматриваются в Telegram; веб-панель показывает текст.
- Адаптивный сайт: обзор, поиск товаров и заказов, цены, видимость, переписка поддержки, журнал действий, статус настройки.
- Закупка Jaha с сохранённым телом и ключом идемпотентности; единый лимитер; кеш каталога; повторные запросы после сбоя; периодическая проверка дополнений даже после completed.
- Раздельные состояния оплаты, закупки и отправки; шифрование выдачи, данных покупателя, переписки и очереди с Fernet; доступ администратора по Telegram ID, сессии сайта, CSRF и ограничение попыток входа.
- Docker Compose, Caddy HTTPS, GitHub Actions (тесты → Docker build → SSH deploy), согласованные снимки SQLite перед деплоем.

## Архитектура и границы первой версии

Python 3.14 + FastAPI + httpx + SQLite WAL. Интерфейс без сборщика и внешних CDN. Один процесс Uvicorn обслуживает сайт, три long-polling бота и фоновые очереди. **Нельзя запускать несколько workers/реплик**: лимитер, poller и отправка очереди рассчитаны на один процесс. Для горизонтального масштабирования потребуется PostgreSQL, распределённые блокировки и отдельные workers.

Количество в заказе выбирается кнопками: минимальная партия, 5 или 10 единиц (в пределах правил товара и наличия). Цены задаются вручную в Stars за единицу; автоматической конвертации USDT/Stars и расчёта чистой прибыли нет. Обзор показывает последние 200 оплаченных заказов и обращений; полная история остаётся в базе.

При неопределённом результате после 12 попыток заказ требует внимания. Новый ключ не генерируется. Возврат Stars доступен после возврата Jaha или документированного окончательного отказа покупки. Ручное рассмотрение, частичные возвраты и спорные результаты решаются с поставщиком. Локальный возврат Stars не вызывает возврат у Jaha.

Очередь сообщений доставляет как минимум один раз: если Telegram принял сообщение, но соединение оборвалось до ответа, сообщение может повториться. Это не вызывает повторную закупку. Дополнения сравниваются по содержимому. Завершённые заказы проверяются примерно раз в час, ожидающие — раз в минуту с учётом общего лимита. На большой истории цикл будет дольше. У поставщика нет гарантированного конечного срока дополнений.

## Локальная проверка

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt
.venv/Scripts/python -m pytest -q
.venv/Scripts/python scripts/preview.py
```

Откройте http://127.0.0.1:8000. Только для локального предпросмотра пароль `local-preview-only-2026`. Preview использует отдельную пустую базу, не запускает ботов и не принимает реальные платежи. Не публикуйте preview в интернете. Для Windows с ограничениями временной папки: создайте `data` и задайте pytest `--basetemp=data/новая-папка-теста`.

## Подготовка сервера

Начальная конфигурация: VPS Ubuntu 24.04 LTS x86_64, 2 vCPU, 4 ГБ RAM, 40 ГБ SSD, постоянный IP. Это инженерная оценка для небольшого магазина, не результат нагрузочного тестирования. Docker поддерживает Ubuntu 24.04: https://docs.docker.com/engine/install/ubuntu/

1. Установить Docker Engine и Compose plugin из официального apt-репозитория Docker.
2. Создать пользователя `deploy`, дать ему доступ к Docker и владение `/opt/market`. Участие в группе docker фактически даёт административные права — используйте отдельный SSH-ключ деплоя.
3. Создать DNS A-запись `admin.example.com` на IP. Открыть 80/443 для Caddy и SSH для администратора/деплоя. База и порт 8000 наружу не публикуются.
4. Создать три бота через BotFather, записать токены и ваш числовой Telegram ID. Самому открыть `/start` у админского бота и бота поддержки, иначе они не смогут присылать уведомления.
5. Получить API-ключ Jaha и пополнить закупочный баланс в его боте.

## Секреты и первый запуск

Локально после установки зависимостей:

```powershell
.venv/Scripts/python scripts/setup_env.py
```

Скрипт создаст `.env` со случайным паролем и DATA_KEY, не выводя их. Отредактируйте остальные поля, перенесите файл защищённым способом на сервер в `/opt/market/.env`, установите права `600`. Не присылайте его в чат и не коммитьте. Сохраните DATA_KEY отдельно: без него восстановленная база не расшифруется. Не меняйте ключ при каждом деплое.

`SHOP_TERMS` — ваши опубликованные условия продажи, возвратов и обработки данных или текст со ссылкой на них (одна строка). При пустом значении оформление покупки закрыто. В `.env` значения с пробелами можно заключать в одинарные кавычки. Не используйте многострочные значения.

На сервере в каталоге исходников:

```bash
export ENV_FILE=/opt/market/.env
docker compose -p market --env-file "$ENV_FILE" up -d --build --wait
docker compose -p market --env-file "$ENV_FILE" ps
```

Откройте домен админки, войдите паролем из `.env`. Синхронизируйте каталог, задайте цены, включите только проверенные товары. Сначала выполните тестовый платёж и контролируемую закупку, проверьте выдачу и ответы поддержки с отдельного покупательского аккаунта.

## GitHub и автодеплой

Достаточно **одного приватного репозитория**, например `tg-marketplace`. Репозиторий пока не подключён: нужен его URL. Не создавайте отдельные репозитории для ботов.

В GitHub создать Environment `production`. Добавить Secrets:

| Секрет | Значение |
|---|---|
| DEPLOY_HOST | IP или имя сервера |
| DEPLOY_USER | deploy |
| SSH_PRIVATE_KEY | Выделенный закрытый SSH-ключ для деплоя |
| SSH_KNOWN_HOSTS | Проверенная запись host key сервера; отпечаток сверить через консоль провайдера |

Токены ботов, пароль, DATA_KEY и JAHA_API_KEY остаются в `/opt/market/.env`; GitHub их не получает. В Repository Variables установить `DEPLOY_ENABLED=true` только после подготовки сервера. Можно настроить required reviewers для Environment, если нужен ручной допуск в production.

Каждый push в `main` запускает тесты и сборку Docker. После успеха архив проверенного коммита отправляется на сервер, собирается образ с тегом SHA, создаётся резервная копия базы и обновляются контейнеры. Deploy считается успешным после healthcheck. При ошибке автоматического отката нет: workflow покажет ошибку, проверьте контейнеры.

Для возврата к предыдущему совместимому релизу:

```bash
bash /opt/market/releases/PREVIOUS_COMMIT_SHA/deploy/deploy.sh PREVIOUS_COMMIT_SHA
```

Откат кода не откатывает платежи и базу. Перед будущими миграциями проверяйте обратную совместимость.

## Резервные копии

Для ежедневной отправки в бесплатный Google Drive подготовлены rclone crypt и systemd timer: [настройка и восстановление](docs/google-drive-backups.md). Это заменяет ручную организацию ежедневного копирования ниже; включается после авторизации Google и тестового восстановления.

```bash
docker compose -p market --env-file /opt/market/.env exec -T app python scripts/backup.py
```

Снимки находятся в `/app/data/backups` внутри постоянного Docker volume. Добавьте ежедневный запуск этой команды через cron, вынос копий на другое хранилище и политику удаления старых копий. Снимки на том же сервере не защищают от потери VPS. Отдельно сохраняйте `.env`/DATA_KEY в защищённом хранилище. Для восстановления остановите app, сохраните текущий volume, восстановите согласованный `.db`, используйте прежний DATA_KEY и только затем запустите один экземпляр app. Проверьте `PRAGMA integrity_check` на восстановленной базе до запуска.

## Проверки и ограничения

Автотесты проверяют дубль оплаты, неверного покупателя/сумму/валюту, безопасные повторы Jaha, довыдачи, шифрование, возвраты, авторизацию/CSRF, доступ к заказам и маршрутизацию поддержки. Реальные Telegram/Jaha запросы, HTTPS и Docker проверяются отдельно после подключения секретов и сервера. Демоданные не выдаются за настоящие продажи.
